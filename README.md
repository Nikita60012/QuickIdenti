# QuickIdenti
## Это мобильное андроид приложение, разработанное как часть дипломного проекта.
Приложение служит мобильным клиентом для FaceSearch backend и взаимодействует с ним через REST API.
## Backend
Backend часть проекта доступна здесь:
### FaceSearch: https://github.com/Nikita60012/FaceSearch
## Стек
- Kotlin
- Android
- Compose
- Retrofit2
- Coil
- Gradle
## Структура проекта
Проект состоит из двух частей:
1. QuickIdenti —  мобильный андроид клиент
2. FaceSearch — backend сервис отвечающий за серверные вычисления и управление данными
## Цель
Проект был разработан как дипломная работа и демонстрирует взаимодействие между андроид приложением и Python backend через REST API.
